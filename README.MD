# House Price Prediction

A machine learning project that predicts house prices using the House Prices dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest

## Project Workflow

1. Loaded the house price dataset
2. Explored and analyzed the data
3. Handled missing values
4. Encoded categorical features
5. Trained a Random Forest Regression model
6. Evaluated the model using MAE and R²

## Model Performance

- MAE: ~17,454
- R² Score: ~0.89

## Project Files

- `analysis.ipynb` — Data analysis, visualization, preprocessing and model training
- `data/train.csv` — Dataset
- `.gitignore` — Files excluded from Git

## Conclusion

The Random Forest model achieved an R² score of approximately 0.89, indicating that the model explains a substantial portion of the variation in house prices.
